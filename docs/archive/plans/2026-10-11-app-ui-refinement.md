## 구현 기준

- 공통 제목/뒤로가기, 간결한 계정·예시·저장 안내. 홈·내 기록·커트 준비 메뉴와 페이지/스크롤 보존 유지
- 기록·경과의 핵심 입력 우선, 선택 정보와 전문은 펼침. 사진 처리·확대, 날짜·부위·가격·이전 담당자 선택 유지
- 기록 선택은 사진·날짜·요약. 자료는 직접 선택, 전체 선택은 현재 커트 또는 불변 snapshot의 적격 자료만 대상. 모두 선택된 상태에서 전체 해제, 부분 선택은 전체 선택
- 작성·미리보기·준비 목록의 복수 요청, 기록 문구 가져오기, 선택 입력, 준비 복사·수정·원본 보기·재진입 보존. 실제 상담 전송 완료를 표시하지 않음
- 로그인·계정·백업도 같은 화면 규칙 사용. 기존 인증·기기 저장·서버 암호화 백업·ZIP 복사본·계정/예시 격리 유지
- URL·쿼리·데이터 형식·API·DB migration·NAS 실행 구성 변경 없음. 기존 사용자 변경과 이전 검증 기록 보존

## 적용 결과

- 공통 제목 행에 뒤로가기 배치. 메뉴와 구분되는 `기록 목록으로`·`준비 목록으로` 이름 사용. 반복 footer 제거, 정상 저장 상태는 짧은 행으로 표시하고 오류·충돌 안내는 항상 표시
- 예시 체험 배지·종료는 항상 표시. 체험 설명·디자이너 목록·초기화는 `체험 안내`에서 접근. 가상 후기와 개인 자료 구분 유지
- 기록은 핵심 입력 → 사진 → 선택 정보 순서. 선택 정보가 있는 수정/복귀 화면은 펼쳐 시작. 상세는 당일 기록 → 사진 → 경과 → 다음 커트 준비 순서. 경과 추가는 경과 제목 옆에 배치
- 디자이너 소개·후기 우선 표시. 모바일 상담 준비 버튼은 하단 메뉴 위에 고정하고 본문 끝에 충분한 공간 확보. 실제 전송을 완료한 것처럼 보이던 미리보기 체크 배너 제거
- 기록 선택에 대표 사진·날짜·요약 추가. 자료는 메모·경과·사진을 각각 선택하는 행으로 표시. 전문 펼침과 사진 확대는 선택 조작과 분리
- 전체 선택은 현재 원본 또는 불변 선택본에서 보여 주는 자료만 포함. 전체 선택 상태에서는 해제, 부분 선택 상태에서는 전체 선택. 새 초안은 미선택 시작, 재진입 상태와 작성한 요청 문장 유지
- 준비 미리보기는 원하는 점을 먼저 표시하고 선택한 참고 자료를 이어 표시. 작성 중/준비 완료 목록에 사진 요약 추가. 로그인·계정·백업도 공통 제목·버튼·간격 적용

## 화면 규칙

흰 배경, 청록 `#14615b`, 연한 표면 `#eef5f3`, 보조 글자 `#526d69`. 기존 SALU 로고와 한국어 font stack 유지. 입력·주 버튼 기본 높이 52px, 보조 조작 44px. 입력 화면 최대 폭 760px. 모바일 한 열, PC에서 맥락이 필요한 화면은 두 열. 모바일 주 메뉴는 68px와 safe-area 기준, 주 행동은 그 위에 배치. 높이 760px 이하에서는 고정/붙는 주 행동을 본문으로 복귀. 별도 내부 스크롤이나 메뉴 복귀 시 폼 재생성 없음.

화면 변경에 따라 접힌 체험 안내를 연 뒤 조작하도록 테스트 수정. 기본으로 펼친 선택 정보·후기를 닫지 않도록 검사 수정. 사진 출처와 날짜를 별도 요약 행에서 확인하고, 메뉴 이름과 뒤로가기 이름을 구분. PC 폼 높이가 짧아졌으므로 스크롤 복원 테스트는 높이 640px에서 실행. 예시의 홈 이동은 체험 종료이므로 선택 복귀 테스트는 예시 안의 내 기록 메뉴로 이동. 기기 저장 긴 시나리오의 최초 시간 초과는 2-worker 재검증에서 통과.

실물 휴대폰의 키보드·Safari·스크린리더·실제 Google/네이버 동의는 이번 검증에 포함하지 않음. 공개 등록 디자이너·상담 송수신·후기 작성·커뮤니티·네이티브 앱은 기존 후속 범위. API·저장 형식·DB·NAS 실행 구성은 이번 개편에서 변경하지 않음.
