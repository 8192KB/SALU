# 조원 시연 안내문

상태: 배포 확인 후 전달. 실제 메시지 전송·조원 초대는 수행하지 않음.

## 복사해서 보낼 내용

SALU 수정본 공유합니다!

접속: https://salu.doyul.dev

폰이나 태블릿에서 로그인 없이 써볼 수 있어요.
1. 커트 기록을 남기고 저장 완료 화면 확인
2. 그 기록에 경과 추가하기
3. 지난 기록을 골라 다음 커트에서 원하는 점 정리하기

기록은 사용한 브라우저에 남아요. 다른 기기에서도 보관하려면 계정 저장이나 ZIP 백업을 사용할 수 있어요. 가입·소셜 로그인은 추가 검증 중이라 우선 로그인 없는 기록 흐름부터 봐 주세요. 실제 상담 전송·후기는 아직 준비 중입니다.

이번에는 메뉴 위치, 글자 크기와 기능 구분, 달력, 저장 완료 흐름을 다듬었습니다. 로그인 후 내 계정에서 디자이너 프로필·매장을 직접 등록하고 기록에 선택하는 기능도 추가했습니다.

피드백은 아래처럼 남겨주면 좋겠습니다.
- 기기·브라우저:
- 헷갈리거나 막힌 화면/버튼:
- 기대한 동작과 실제 동작:
- 가능하면 화면 캡처:

특히 처음 무엇부터 해야 하는지, 커트와 경과가 구분되는지, 저장한 뒤 어디로 가야 하는지 봐 주세요. 피드백 모아서 수정하고 발표 자료에 반영할 예정입니다.

코드: https://github.com/8192KB/SALU/tree/feature/personal-storage-backup
비공개 저장소라 초대를 수락해야 코드가 보입니다. 화면 테스트는 Git이나 Docker 설치 없이 위 웹 주소로 접속하면 됩니다.

## 전달 전 확인

공개 주소의 최신 이미지·HTTPS·기록/사진/경과·달력·완료 결과 확인 후 상태 갱신. 실제 가입/소셜 제공자 동의·실물 기기 확인은 별도 검증이며 시연 성공과 구분.
